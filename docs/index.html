How the kernel works

Pyodide boots once inside a Manifest V3 sandboxed iframe — full Python power without weakening the extension's CSP.

you → app.js ──postMessage──▶ sandbox (Pyodide WASM)
                ◀──outputs / timings / variables──
sandbox ──one-time──▶ CDN (kernel download only)

Install in 30 seconds

Chrome, Edge, Brave, Opera, Arc, Vivaldi, Yandex — any Chromium browser.

1. Download the release ZIP (or git clone https://github.com/Ahmedbakr78/Heros_Jupter.git).
2. Open chrome://extensions (Edge: edge://extensions) and enable Developer mode.
3. Load unpacked → select the Heros_Jupter folder (contains manifest.json).
4. Pin Heros NoteBook, click the icon — drop an .ipynb or load the demo.
5. Optional: Details → Allow access to file URLs for file:// auto-open.

Updating? Press Reload ↻ on the extension card — it must read v1.1.0.

Questions

Full 30-question list in the README.

Is it really free?

Yes — MIT licensed, unlimited notebooks, cells, runs and exports. No accounts, no quotas.

Do I need Python or Jupyter installed?

No. Python runs inside the browser as WebAssembly via Pyodide. There is no server component.

Do my notebooks upload anywhere?

Never. Files are read in memory; only recents/marks/preferences touch chrome.storage.local on your machine.

Does pip install work?

Yes — pure-Python wheels and the Pyodide scientific set (numpy, pandas, matplotlib, …) install from any cell or the package manager.

Can I export back to Jupyter?

Yes — .ipynb round-trips with outputs; .py, .md, .html, .txt and print/PDF cover everything else.
